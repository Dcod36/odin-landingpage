# Landing Page Project

This project was completed as part of **The Odin Project – Foundations Course**.

The goal of this project was to build a full landing page from a provided design using only HTML and CSS, with a strong focus on **Flexbox layout**.

## Project Description

I recreated a landing page design by breaking it down into sections (header, hero, information, quote, call-to-action, and footer) and styling each section step by step.  
The project emphasizes building layout structure first with HTML and then applying styles using external CSS.

This project is not focused on responsiveness yet and is designed for desktop viewing, as specified in the assignment.

## What I Learned

By completing this project, I practiced and improved my understanding of:

- Writing semantic HTML structure
- Using external CSS stylesheets
- Understanding the CSS box model
- Using **Flexbox** for layout and alignment
  - `display: flex`
  - `justify-content`
  - `align-items`
  - `gap`
  - Nested flex containers
- How parent and child elements interact in Flexbox
- Debugging layout issues caused by incorrect HTML structure
- Styling buttons and understanding browser default styles
- Committing changes early and often using Git
- Pushing a project to GitHub and publishing it with GitHub Pages

## Reflection

This project helped me understand how to approach larger layouts without feeling overwhelmed by breaking the page into smaller sections and solving one layout problem at a time.  
It also reinforced the importance of correct HTML structure before applying CSS and how powerful Flexbox is for building modern layouts.
